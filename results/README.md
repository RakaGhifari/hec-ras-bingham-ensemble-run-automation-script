# Results

Large HEC-RAS HDF files and generated intermediate results are intentionally excluded from the repository.

Recommended public outputs are compact CSV tables documenting:

- parameter sets;
- successful/failed simulations;
- HDF quality-control statistics;
- travel-time results;
- spatial validation metrics;
- sensitivity-analysis results;
- the final master spatial-temporal table.

Large outputs can be archived separately or deposited in an appropriate research data repository.
